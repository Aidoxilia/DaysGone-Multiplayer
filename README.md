# Days Gone Multiplayer — Co-op Mod

An **unofficial, fan-made multiplayer mod for Days Gone (PC)**, built to let friends experience the original game together instead of replacing it with a separate game mode.

> [!IMPORTANT]
> **Development status: Experimental / Early Alpha.** The mod is actively being improved. Features shown in development builds may have bugs, and compatibility across different PCs and networks is still being tested.

## Features

* **3+ player support** in development tests.
* **Real-time campaign synchronization:** main missions, side jobs, objectives, triggers, scripted events, QTEs and tutorials.
* **Synchronized NPCs and combat:** enemies, hordes, animations, states, attacks and damage.
* **Shared world interactions:** doors, vehicle hoods and trunks, loot on the ground, explosive barrels and destructible objects.
* **Inventory, progression and save synchronization.**
* **Motorcycle and vehicle synchronization**, including shared movement and physics.
* **Time synchronization** and support for players exploring different areas of the map.
* **Co-op cutscenes**, with synchronization to wait for other players and coordinate skipping.

These systems are implemented or under active refinement; **not every scenario has been fully validated**.

## Installation

1. Make sure you own and have installed **Days Gone on PC**.
2. Open this repository's **Releases** section and download the latest mod **`.zip`** file.
3. Open your **Days Gone installation directory**.
4. **Extract the contents of the ZIP directly into the game's root folder**, keeping the archive's folder structure intact.
5. **Launch Days Gone normally.** The mod files should already be in their correct locations.

**Example installation directory:**

```text
F:\SteamLibrary\steamapps\common\Days Gone\
```

> [!TIP]
> In Steam, open **Days Gone → Properties → Installed Files → Browse** to find the installation folder. Be careful not to extract everything into an extra nested folder such as `Days Gone\DaysGone-Multiplayer-v0.x\`.

**No source-code build or separate installer is required.** Installation is designed to be a simple ZIP extraction.

## Multiplayer & Compatibility

* Every player should use the **same mod version**.
* Multiplayer features and setup instructions may change between experimental releases; check the **release notes** for your version.
* Different PCs, network configurations and game builds are still being tested. A successful local or LAN test does **not** guarantee flawless Internet play.
* Back up your game saves before testing, especially when using progression or save synchronization.

## Known Issues & Feedback

This is an experimental mod. You may encounter FPS drops, desynchronization, crashes or unexpected mission behavior while development continues.

If you report an issue, please include your **mod version**, **game version**, what happened, steps to reproduce it and relevant logs if available. Remove personal information and public IP addresses from logs before posting them.
